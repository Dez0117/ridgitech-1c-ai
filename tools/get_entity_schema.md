# get_entity_schema

**Назначение:** получить описание опубликованного источника и его возможностей.

**Вход:** `entity_name` из определения метрики.

**Выход:** поля, типы, ключи, связи, функции, параметры виртуальных таблиц,
карта `$expand`/client-side join и версия каталога.

**Инструкция:** проверяй источник перед первым использованием и при смене версии.
Планируй запрос по указанным возможностям. Раскрытие связей и получение страниц
делегируй слою данных.
