# get_customer_balances

**Назначение:** получить остатки взаиморасчётов с покупателями на момент времени.

**Вход:** `metric_id`, `as_of`, `organization_id`, при необходимости `counterparty_ids`
и разрешённые разрезы.

**Выход:** остатки, единица/валюта, момент среза, источники и правила трактовки знака.

**Инструкция:** используй для остатков и задолженности покупателей по выбранному
определению. «На сегодня» конкретизируй по временной зоне и методологии среза.
Отрицательный остаток трактуй по определению метрики.

## Условия вызова

Вызывай только шаг, зарегистрированный через `submit_query_plan`, с теми же аргументами.
При `PLAN_REQUIRED` сначала передай план; при `DEPENDENCY_PENDING` выполни зависимости.
При `INCOMPLETE_DATA` предложи сузить запрос и не выдавай частичный итог.
