# get_sales_turnovers

**Назначение:** получить обороты продаж за период.

**Вход:** `metric_id`, `period`, `organization_id`, разрешённые `group_by` и `filters`.

**Выход:** итоги/таблица оборотов, единица/валюта, источники, условия расчёта и полнота.

**Инструкция:** используй для вопросов про продажи по согласованной методологии.
Группировки и фильтры бери из определения метрики. Итог используй из API.

## Условия вызова

Вызывай только шаг, зарегистрированный через `submit_query_plan`, с теми же аргументами.
При `PLAN_REQUIRED` сначала передай план; при `DEPENDENCY_PENDING` выполни зависимости.
При `INCOMPLETE_DATA` предложи сузить запрос и не выдавай частичный итог.
