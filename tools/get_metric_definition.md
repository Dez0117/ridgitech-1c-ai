# get_metric_definition

**Назначение:** получить согласованную методологию расчёта.

**Вход:** `metric_id` из каталога.

**Выход:** источник истины, формула, единица/валюта, обязательные фильтры,
параметры времени, разрезы и операции, правила знака/округления, связи и версия.

**Инструкция:** используй определение перед составлением плана. Сохраняй обязательные
условия. Для остатков выбирай согласованную виртуальную таблицу, для оборотов -
соответствующее определение периода. Неподтверждённая методология требует согласования.
