# resolve_dimension

**Назначение:** превратить название из вопроса в идентификатор параметра.

**Вход:** разрешённое `dimension` (`organization`, `counterparty`, `direction`)
и `query` - название или его фрагмент.

**Выход:** доступные кандидаты с идентификатором, названием и признаками для различения.

**Инструкция:** используй для объектов, названных текстом. При нескольких совпадениях
уточни выбор. Передавай в расчёт идентификатор выбранного объекта.
