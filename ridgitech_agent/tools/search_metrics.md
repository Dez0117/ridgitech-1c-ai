# search_metrics

Находит доступные определения метрик по бизнес-вопросу пользователя.

Вызывай в начале нового аналитического вопроса или при изменении смысла показателя.
Передай `query`: вопрос либо описание показателя, например «дебиторская задолженность».
Базу и права задаёт backend; передавать их аргументами этого tool не нужно.

Результат — до пяти кандидатов с `metric_id`, названием, описанием, статусом
подтверждения и оценкой совпадения. Оценка помогает ранжированию и не является
вероятностью правильности финансовой трактовки.

Если кандидатов нет — сообщи, что показатель пока не поддерживается. Если несколько
кандидатов подходят по смыслу — уточни выбор. Для выбранной метрики обязательно
вызови `get_metric_definition`; не строй расчёт по одному названию.

Основание: ФТ-2.1 и ФТ-4.3 ТЗ.
