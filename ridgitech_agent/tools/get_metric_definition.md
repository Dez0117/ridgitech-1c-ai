# get_metric_definition

Возвращает полное определение доступной метрики и версии семантики/каталога.

Вызывай после выбора кандидата, до построения плана. Передай `metric_id`, полученный
из `search_metrics`. При ошибке устаревшей версии получи определение заново.

Используй источник, поля, обязательные фильтры, единицу, точность и доступные разрезы
из результата. Не меняй финансовый смысл и не заменяй источник истины похожей
сущностью. Если определение не содержит нужного правила или шаблона расчёта —
сообщи об ограничении, не додумывай методологию.

Статус `draft` не разрешает исполнение. `demo` допустим только в явно включённом
тестовом контексте. Для работы с реальными финансовыми данными требуется `approved`.
После определения проверь источник через `get_entity_schema`.

Основание: ФТ-2.1–2.3 и ФТ-3.5 ТЗ.
