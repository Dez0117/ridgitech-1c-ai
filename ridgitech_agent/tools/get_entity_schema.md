# get_entity_schema

Возвращает поля, типы, ключ и разрешённые expand paths доступного источника.

Вызывай после получения определения метрики, до отправки плана. Передай
`entity_name` из определения. Не придумывай имя сущности по вопросу пользователя.
Схема относится к базе, выбранной backend.

Используй только опубликованные в каталоге поля и проверенные способы связи.
Не применяй `$expand` там, где это запрещено ТЗ и картой возможностей источника.
Если каталог не описывает нужную виртуальную таблицу, её параметры или связь,
сообщи о нехватке данных для планирования, не выдумывай их.

Ошибка отсутствия/недоступности источника не означает пустую выборку. При расхождении
схемы и определения метрики сообщи о необходимости исправить каталог или маппинг.

Основание: ФТ-1.2–1.4 и ФТ-3.3 ТЗ.
