# Golden set для проверки AI агента 1С

Версия 1 от 16 ноября 2026 года. Проект набора для согласования с заказчиком.

Этот документ задаёт вопросы и ожидаемые результаты независимо от текущих ответов модели. Он используется для повторной проверки качества агента. В основном наборе 37 сценариев; восемь дополнительных целевых вопросов приведены в конце и пока не входят в оценку.


## Общие условия

Основная дата контекста - 16.11.2026, зона Europe/Moscow. В G20 дата специально зафиксирована на 15.02.2025. Если не указано иное, в интерфейсе выбрано ООО «Демо-Софт». В G03 и G25 организация заранее не выбрана, в G09 выбрано ООО «Демо-Торг». G37 проверяет недоступную организацию.

Числа приведены в ед. учёта. Валюта не подтверждена; не следует автоматически указывать рубли. Начало периода включительно, конец исключительно. «С 15 по 20» включает весь день 20 числа. Пустая выборка означает отсутствие данных, а не доказанный нулевой итог.

Для расчётного ответа проверяются операция, период, организация, направление, сумма до 0,01, число исходных движений, полнота результата, источники и предупреждение о демонстрационной методике. Для уточнения и отказа расчёт выполняться не должен. Ошибка API или таймаут не считаются корректным отказом.


## Состав набора

Основание эталонов - ограниченный снимок 556 реальных движений 1С. Суммы рассчитаны отдельно от сервиса через Decimal; для финансовой приёмки требуется ручная сверка с отчётом заказчика. Сам набор не является уже утверждённым приёмочным тестом.

В машиночитаемой версии сохранены точные UUID, границы периодов и критерии оценки. В этой версии используются понятные названия и номера G01-G37; технические идентификаторы сохранены для сопоставления.
